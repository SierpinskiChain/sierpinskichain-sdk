# SDK Examples

This folder is published with `@sierpinskichain/sdk` and provides runnable references for common flows.

Included examples:
- `wallet-generate.ts`
- `send-transaction.ts`
- `contract-deploy-call.ts`
- `storage-upload.ts`
- `ai-infer.ts`
- `subscribe-events.ts`
- `wallet-ui.tsx`

Environment variables used by examples:
- `SIERPINSKI_RPC_URL` (default: `http://127.0.0.1:40406`)
- `SIERPINSKI_WS_URL` (default: `ws://127.0.0.1:40407/ws`)
